# golem · how it works · 15 s, 1080×1080, 60 fps

Mécanique en 3 lignes :
1. tu tapes une phrase, elle devient un agent avec des règles lisibles et un backtest.
2. l'agent calle les tokens de robinhood chain qui passent les 7 checks du gate, en public.
3. s'il franchit sa ligne de perte, il est viré, et son historique reste.

Storyboard (vraies captures du site animées, style startup) :
- 0,0–2,5 s · le logo G se dessine, la barre finit en nœud orange · "build an agent"
- 2,5–5,5 s · capture Studio : la phrase se tape dans le champ, les curseurs se placent tout seuls
- 5,5–8,0 s · capture backtest : la courbe agent vs holding se trace, "+13% vs holding" en surimpression
- 8,0–11,0 s · capture Floor : les lignes PASS / BLOCKED défilent, "7 checks before any call"
- 11,0–13,5 s · badge d'agent tamponné FIRED, braises · "fire it when it loses"
- 13,5–15,0 s · logo + getgolem.xyz
Sans piste audio.
